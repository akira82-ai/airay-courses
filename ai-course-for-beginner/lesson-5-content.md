# Lesson 5：AI 内容生成与文案生产

## 课程定位

这节课讲的不是“让 AI 帮我写一句文案”，而是如何用 AI 建立一套稳定的内容生产流程。

面向场景：

- 营销文案
- 产品营销文案
- 公众号内容
- 朋友圈内容
- 社群通知与活动推广

核心观点：

> AI 写文案最容易失败，不是因为它不会写，而是人没有给判断标准。

记忆框架：

```text
定目标 -> 给素材 -> 搭结构 -> 出变体 -> 做验收
```

## 60 分钟结构

| 时间 | 模块 | 目标 |
|---|---|---|
| 0-5 分钟 | AI 写内容的定位 | 明确 AI 是作者、编辑、策划助理和风格分析师，但不是最终负责人 |
| 5-15 分钟 | 好文案的基础要求 | 讲清目标、受众、卖点、证据、语气、渠道、行动指令 |
| 15-30 分钟 | 从 0 到 1 写文案 | 先写 Brief，再出角度、结构、标题和初稿 |
| 30-45 分钟 | 从 1 到 100 批量生产 | 做标题变体、渠道改写、语气变体和 A/B 候选 |
| 45-55 分钟 | 风格蒸馏与复刻 | 拆风格，不照抄；迁移风格特征，不冒充身份 |
| 55-60 分钟 | 验收与风险边界 | 用清单判断 AI 文案是否可用 |

## 模块 1：AI 写内容的定位

AI 在内容生产里可以扮演四个角色：

- 作者：帮你生成初稿、标题、短文案、长文结构。
- 编辑：帮你删废话、调语气、增强逻辑、降低 AI 味。
- 策划助理：帮你找角度、拆卖点、设计内容结构。
- 风格分析师：帮你拆解样本文案的语气、节奏、句式和表达习惯。

但最终判断不能交给 AI。人要负责三件事：

- 目标是否正确。
- 信息是否真实。
- 输出是否适合发布。

可以这样告诉团队：

> AI 可以提高生产速度，但不能替你判断什么内容应该被发布。

## 模块 2：好文案的基础要求

一条可用文案至少要回答六个问题：

| 问题 | 含义 | 常见失败 |
|---|---|---|
| 写给谁 | 明确目标对象 | 所有人都想打动，最后谁也打不动 |
| 解决什么问题 | 明确用户痛点或任务 | 只介绍自己，不回应对方关心 |
| 给什么利益 | 明确用户能得到什么 | 堆功能，缺少收益 |
| 凭什么相信 | 给证据、案例、数据、机制 | 全是形容词，没有可信支撑 |
| 希望做什么 | 明确行动指令 | 看完不知道下一步 |
| 在哪里发布 | 适配渠道和字数 | 公众号味写进朋友圈，朋友圈味写进正式通知 |

基础 Brief 模板：

```text
我要写一段【文案类型】。
目标用户是：
发布渠道是：
这段文案要达成的目标是：
核心卖点有：
可用证据有：
语气要求是：
字数限制是：
不要出现：
请先整理成一份文案 Brief，不要直接写正文。
```

讲解重点：

- Brief 是写前判断，不是写后补救。
- 没有 Brief，AI 只能按通用语料猜。
- Brief 写得越清楚，后面改稿成本越低。

## 模块 3：从 0 到 1 写文案

从 0 到 1 不要直接说“帮我写一段文案”。标准流程是：

```text
Brief -> 角度 -> 结构 -> 标题 -> 初稿 -> 自评 -> 改稿
```

第一步：让 AI 先出角度。

```text
基于下面这份 Brief，请给我 3 个文案切入角度：
1. 痛点型
2. 利益型
3. 场景型

每个角度请说明：
- 适合打动谁
- 核心表达是什么
- 可能的标题方向

先不要写完整正文。
```

第二步：确认结构，再写初稿。

```text
我选择第 2 个角度。
请先给出文案结构，包含：
- 开头怎么抓注意力
- 中间如何展开卖点
- 证据放在哪里
- 结尾如何引导行动

确认结构后，再写一版 150 字以内的初稿。
```

第三步：让 AI 自评。

```text
请作为严格编辑，检查这版文案：
- 哪里太空泛
- 哪里不具体
- 哪里像套话
- 哪一句最应该删掉
- 哪一句最应该加强

先给诊断，再给修改版。
```

讲解重点：

- 初稿的目标不是完美，而是有明确方向。
- 角度比措辞更重要。
- AI 写完后要先做诊断，不要直接要求“优化一下”。

## 模块 4：从 1 到 100 批量生产

从 1 到 100 的核心不是让 AI 多写几版，而是让 AI 按变量系统化扩展。

常见变量：

- 标题变量：结果型、痛点型、反差型、数字型、问题型。
- 渠道变量：朋友圈、公众号开头、社群通知、产品介绍、短视频口播。
- 语气变量：专业、轻松、克制、强转化、真实分享。
- 用户变量：新用户、老用户、管理者、一线员工、潜在客户。

标题变体模板：

```text
基于下面这版文案，请生成 20 个标题候选。

请按 5 类输出：
1. 结果型
2. 痛点型
3. 反差型
4. 数字型
5. 问题型

要求：
- 不夸大承诺
- 不标题党
- 每个标题不超过 22 个字
- 每类选出你认为最稳的 1 个，并说明理由
```

渠道改写模板：

```text
请把下面这段文案改写成 4 个渠道版本：
1. 朋友圈版：真实、自然、有个人表达
2. 公众号开头：有钩子，有问题意识
3. 社群通知：直接、清楚、有行动指令
4. 产品介绍：突出卖点、场景和可信证据

要求：
- 保留核心信息
- 不新增未经确认的事实
- 每版说明适合什么场景
```

A/B 候选模板：

```text
请基于同一个卖点，生成 3 个 A/B 测试候选版本。

每个版本都要说明：
- 主打人群
- 主打利益点
- 风格差异
- 可能风险

不要判断哪一版一定最好，只给适用场景。
```

讲解重点：

- 批量生产不是堆数量，而是有控制地改变变量。
- 不要让 AI 自称“最佳版本”，要让它说明适用场景。
- 内容规模化的关键是统一 Brief、统一变量、统一验收。

## 模块 5：风格蒸馏与复刻

风格复刻不等于照抄。正确做法是先拆风格，再迁移特征。

风格拆解维度：

- 结构：先讲问题、先讲故事，还是先给结论。
- 句长：短句密集，还是长句解释。
- 节奏：快、慢、强转折、层层递进。
- 语气：克制、犀利、亲切、专业、松弛。
- 词汇：常用词、口头禅、行业词、情绪词。
- 开头：提问、反差、故事、结论、场景。
- 结尾：行动指令、金句、总结、开放问题。

风格拆解模板：

```text
请分析下面这段文案的风格，不要改写。

请按以下维度输出：
- 结构方式
- 句子长短
- 节奏特点
- 语气特点
- 常用表达
- 开头方式
- 结尾方式
- 可以迁移的风格特征
- 不应该照抄的具体表达
```

风格迁移模板：

```text
请参考上面的风格分析，为下面的新主题写一版文案。

要求：
- 只迁移风格特征
- 不复用原文句子
- 不模仿具体个人身份
- 不新增未经确认的事实
- 保持新主题的信息准确
```

安全边界：

- 可以学习结构，不要复制句子。
- 可以学习节奏，不要冒充本人。
- 可以学习语气，不要复刻敏感个人身份。
- 可以参考表达习惯，不要照搬具体观点和案例。

讲解重点：

> 风格复刻的目标不是“写得像某个人”，而是把有效表达方式迁移到自己的内容里。

## 模块 6：不同文案类型的验收标准

不同职业写作可以共用同一套生产流程，但验收标准不同。

| 类型 | 重点看什么 | 常见问题 |
|---|---|---|
| 营销文案 | 转化、行动指令、利益点 | 口号多，行动弱 |
| 产品营销文案 | 痛点、卖点、证据 | 功能堆砌，用户收益不清 |
| 公众号内容 | 选题、观点、结构 | 标题强，正文散 |
| 朋友圈文案 | 真实感、语气、传播动机 | 太像广告，缺少个人感 |
| 社群通知 | 信息清晰、时间地点、动作 | 看完不知道要做什么 |

这页可以作为课程中的关键转折：

> 不是所有文案都追求“好看”。不同场景要先定义“什么叫可用”。

## 模块 7：验收与风险边界

AI 文案交付前必须过五个问题：

| 检查项 | 判断问题 |
|---|---|
| 清楚吗 | 目标、受众、行动是否明确 |
| 可信吗 | 是否有证据，是否夸大承诺 |
| 具体吗 | 是否有真实场景、数字、对象、动作 |
| 像人话吗 | 是否过度 AI 味、空泛、堆形容词 |
| 安全吗 | 是否有版权、品牌、合规、隐私风险 |

验收模板：

```text
请按下面 5 个维度检查这版文案：
1. 清楚：目标、受众、行动是否明确
2. 可信：是否有证据，是否夸大承诺
3. 具体：是否有场景、对象、动作
4. 人话：是否有 AI 味、空话、套话
5. 安全：是否有版权、品牌、合规、隐私风险

请先指出问题，再给修改版。
```

高风险表达要避免：

- 保证收益。
- 绝对化表述。
- 未经确认的数据。
- 冒充用户真实体验。
- 照抄别人的句子和案例。
- 暴露客户、团队、业务敏感信息。

### 可用素材 1：短视频标题优化原则

来自“短视频文案”表格，适合补充到“从 1 到 100 批量生产”模块。

```text
优化短视频文案标题

目标：
让短视频标题和内容更吸引人。

遵循原则：
1. 自嘲语气：别人的快乐建立在我的痛苦之上
2. 借力热点：突出个人最深刻的感悟
3. 扩大受众：要让更多人感兴趣，而不是只打动很小圈层
4. 放大猎奇：围绕核心点扩展八卦和猎奇信息
5. 强化情绪：极度的爱和极度的恨，本质都是情绪强度
6. 向下兼容：让老年人、年轻人都能一听就懂
7. 吐槽对立：反向表达，激发用户情绪和好奇
```

课程讲法：

- 这组原则适合短视频和社交媒体，不适合正式品牌稿全文照搬。
- 可以把它作为“标题变量”的一组维度。
- 要提醒团队：猎奇和情绪可以用，但不能牺牲事实和品牌安全。

### 可用提示词 1：内容改写与摘要

来自“内容/文案优化”，适合补充到“从 0 到 1”的自评和改稿环节。

```text
请总结提炼上文的核心观点，并完成以下任务：
1. 提炼 3 点即可
2. 加入你的评价和意见
3. 使用【详解 xx】的风格
4. 用小学生能听懂的语言回复
5. 控制在 500 字左右
```

课程讲法：

- 这条提示词适合把复杂内容转成通俗解释。
- 可以用于公众号、社群说明、朋友圈科普。
- “小学生能听懂”不是降低质量，而是降低理解门槛。

### 可用提示词 2：社交媒体干货整合

来自“X/推特指定主题的技巧整合”，适合补充到“从 1 到 100”和“公众号/社交媒体内容”模块。

```text
你是一个专业的全网内容研究员和文档整理专家。
请针对指定产品，从 X、Reddit、Hacker News、YouTube 评论等社区中，
搜集最近 1 个月内的用户分享内容，优先高赞、高评论、高互动的 thread、
论坛讨论、视频评论等。

重点提取：
- 使用技巧
- 独家经验
- 避坑指南
- 提示词模板
- 常见错误

整理输出为一篇适合拆分成社交媒体线程的 Markdown 文档。
每条内容必须包含：
- 核心干货概要
- 详细展开说明
- 可拿来即用的操作流程或模板
```

课程讲法：

- 这不是直接写文案，而是先做素材搜集和干货整理。
- 适合产品营销文案的前置调研。
- 能补强“凭什么相信”这一项，避免文案只有口号没有依据。

### 可用提示词 3：产品深度评测文案

来自“X/推特指定主题的深度评测”，适合补充到“产品营销文案”和“证据型内容”模块。

```text
你是一个专业的 AI/Agent 产品评测作者。
请以真实用户视角，基于公开搜索数据，撰写一篇真实、客观、深度且可读性强的评测报告。

目标：
帮助读者判断「这个产品到底怎么样，值不值得用，有没有坑」。

必须覆盖：
- 用户痛点和初步结论
- 样本来源和数据概述
- 亮点深度剖析
- 槽点与避坑指南
- 争议点与不同声音
- 谁适合用，谁需要谨慎
- 性价比与竞品对比
- 实用建议与最佳实践
- 最终行动建议

要求：
- 所有结论必须有数据或引用支撑
- 不绝对化表达
- 不编造用户反馈
- 如果平台反馈较少，明确注明
```

课程讲法：

- 这是“产品营销文案”的高质量版本，不是硬卖。
- 它把营销表达建立在用户反馈、竞品对比和避坑建议上。
- 适合讲“可信证据”比“形容词堆叠”更重要。

### 可用提示词 4：产品实用指南

来自“X/推特指定主题的实用指南”，适合补充到“公众号长文”“教程型内容”和“结构化指南”模块。

```text
你是一个专业的产品使用指南撰写专家。
请基于真实搜索结果，生成一份全面、实用、易读的使用指南。

输入参数：
- 产品名称
- 用户水平：新手 / 中级 / 高级
- 搜索时间范围
- 输出语言

内容要根据产品类型自动调整关注维度：
- AI/Agent 类：prompt 工程、幻觉控制、工具调用、多模态、自定义 Agent
- SaaS/效率工具类：模板、工作流、插件集成、自动化规则
- 设计/创作工具类：参数调优、风格控制、批量处理、版本管理
- 硬件类：配件兼容、固件更新、维护和使用场景

输出结构：
1. 数据概述
2. 快速上手
3. 核心技巧
4. 高级玩法
5. 常见坑与解决方案
6. 谁适合用，以及进一步资源

要求：
- 所有关键主张有来源支撑
- 信息不足时明确说明
- 多用列表、表格、短句和示例
```

课程讲法：

- 这条提示词适合把“产品说明”变成“可执行教程”。
- 它的重点不是文采，而是让用户知道第一步、第二步、第三步怎么做。
- 可以用于产品营销内容的后半段：先建立兴趣，再给使用路径。

### 可用案例：短视频文案结构

来自“短视频文案”表格，适合补充到“渠道改写”模块。

```text
标题：一句话制造冲突、结果或猎奇点
引子：用问题、反差、情绪或场景快速抓注意力
主体：通常拆成 3 个观点，每个观点要有解释和判断
结尾：给行动指令，引导评论、收藏、转发或继续关注
```

结构特点：

- 标题直接制造反差或冲突。
- 引子先给情绪，不先讲背景。
- 主体通常用 3 点展开。
- 每一点都带有判断，不只是陈述事实。
- 结尾经常用问题引导评论。

课程讲法：

- 同一份素材，换渠道时不能只改语气，还要改结构。
- 短视频文案追求前 3 秒抓注意力，公众号和产品稿更重视证据链。
- 这页可以用来解释“渠道适配”不是简单缩写。
